# Life on a Margin

**You can beat the market. You can't beat time.**

Life on a Margin is an open-world financial career and life simulation RPG in development by Klord Fernandez Cayetano. This repository contains its public website.

| Edition | Intended distribution | Status |
| --- | --- | --- |
| Life on a Margin: The First Trade | Free browser demo | In development |
| Life on a Margin | Downloadable game, with Windows as the first target | In development |

The website includes an overview, release status and answers to early player questions. Its artwork is original concept art. Gameplay media and release links will be added after verification.

## Local preview

Run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000/`. The site uses HTML, CSS and a local image. It does not need a build command.

Run `python3 tests/smoke_test.py` to check navigation anchors, asset references, heading order and unreleased edition copy.
